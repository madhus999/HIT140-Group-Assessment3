## Model comparison and diagnostics

Models were compared using nested grouped cross-validation: five outer folds estimate performance, while four inner folds tune Ridge, Lasso, and Random Forest hyperparameters within each outer training fold. Both rows from a match stay in the same fold, and every model and the mean baseline use the same held-out match folds. RMSE is measured in goals; lower values are better. The table reports mean RMSE and standard deviation across the five outer folds.

| model | mean grouped CV RMSE | fold SD |
|---|---:|---:|
| Random Forest (tuned) | 1.189 | 0.160 |
| OLS | 1.214 | 0.144 |
| Lasso (tuned) | 1.216 | 0.137 |
| Ridge (tuned) | 1.219 | 0.145 |
| Mean baseline | 1.383 | 0.140 |

The tuned Random Forest has the lowest average validation RMSE, but its advantage over OLS is small (0.025 goals) relative to fold-to-fold variability. OLS remains the required, interpretable linear model; all three regression models improve on the mean baseline in this validation. This comparison is evidence of benchmarking, not proof that the more complex model is reliably superior on a small dataset.

## Diagnostic checks

- The Breusch-Pagan test indicates heteroskedasticity (LM p = 0.0023; F-test p = 0.0017), and Shapiro-Wilk rejects normal residuals (p < 0.0001). These limitations are visible in the residual diagnostic plots.
- VIF values range from 1.047 to 2.527, with no severe multicollinearity indicated.
- The target variable (`team_goals`) is discrete and right-skewed; OLS is therefore an interpretable baseline rather than a distribution-perfect model.
- Because each match contributes two rows (one per team), cluster-robust standard errors by `match_id` were used in the reported OLS model.
